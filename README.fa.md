# PVNetwork

[English](README.md) · [راهنمای تصویری](docs/UI-GUIDE.fa.md) · [نصب](docs/INSTALLATION.fa.md) · [کنسول](docs/CLI.fa.md)

PVNetwork پنل مدیریت کاربران OpenVPN، اشتراک‌ها، نمایندگان و نودهاست. رابط وب چندزبانه و کنسول عملیاتی ۲۵بخشی فارسی و انگلیسی دارد. پنل سیاست حساب را مدیریت می‌کند و نودها اتصال VPN، مصرف و وضعیت نشست را ارائه می‌دهند.

## وضعیت انتشار و تغییرات

**نسخه v1.0.56، QA عمومی بررسی‌شده است.** تغییر نسبت به v1.0.55: گواهی جدیدِ نصب‌کننده، hook امن reload شدن Nginx پس از تمدید موفق دارد. CI دقیق، دانلود ناشناس آرشیو و نصب عمومی هر سه توزیع روی x86_64 و ARM64 واقعی پاس شدند. [شواهد و gateهای باقی‌مانده Stable](docs/VALIDATION-v1.0.56.md) · [یادداشت فارسی](docs/RELEASE-NOTES-v1.0.56.fa.md) · [English notes](docs/RELEASE-NOTES-v1.0.56.md). استقرار Production یا تغییر گواهی زنده انجام نشده است.

**نسخه v1.0.55، QA بررسی‌شده و روی پنلِ مجاز مستقر شده است.** CI دقیق، bootstrap عمومی سه توزیع، بکاپ/canary و کنترل‌های Production پاس شده‌اند. آخرین نسخه پایدار پشتیبانی‌شده تا عبور از gateهای گسترده‌تر همچنان v1.0.37 است. پیش از نصب یا ارتقا، [شواهد و محدودیت‌ها](docs/VALIDATION-v1.0.55.md) و یادداشت همان نسخه را بخوانید.

تغییر نسبت به v1.0.54: بکاپ native فقط فایل تشخیصیِ در حال نوشتن `data/app.log` را از آرشیو قابل‌بازیابی کنار می‌گذارد؛ کنترل ثبات کلیدها، اعتماد SSH و بقیه فایل‌ها حفظ می‌شود. لاگ روی سرور باقی می‌ماند. این اصلاح خطایی را رفع می‌کند که ارتقا را پیش از فعال‌سازی متوقف کرده بود. [یادداشت فارسی](docs/RELEASE-NOTES-v1.0.55.fa.md) · [English notes](docs/RELEASE-NOTES-v1.0.55.md).

![داشبورد فارسی با داده ساختگی Demo](docs/images/v1.0.54/fa/desktop/dashboard.png)

تصاویر از رابط فعلی با داده ساختگی Demo گرفته شده‌اند و اطلاعات مشتری یا تنظیمات Production ندارند. تصویر، اثبات سلامت سرویس واقعی نیست. نسخه‌های 1.0.55 و 1.0.56 رفتار بکاپ و چرخه گواهی را تغییر می‌دهند و رابط آن‌ها با تصاویر 1.0.54 یکسان است.

## از اینجا شروع کنید

1. [پیش‌نیازها و روش دسترسی](docs/INSTALLATION.fa.md) را بخوانید. برای ارزیابی خصوصی Setup Mode و برای کنترل نود راه دور دامنه HTTPS واقعی انتخاب کنید.
2. روی سرور تازه و واجد شرایط نصب کنید، اطلاعات ورود اولیه را از فایل خصوصی بخوانید و `sudo pvnetwork doctor --json` را بررسی کنید.
3. [نود را اضافه کنید](docs/NODE-INSTALLATION.fa.md)؛ سپس طبق [آموزش کاربران](docs/UI-GUIDE.fa.md#2-users) حساب بسازید و پروفایل و صفحه اشتراک را دریافت کنید.
4. پیش از ارائه به مشتری، اتصال واقعی VPN و ثبت مصرف را روی نود آزمایشی خودتان بررسی کنید. سبز بودن پنل یا دانلود فایل به‌تنهایی اتصال تونل را ثابت نمی‌کند.
5. بکاپ خصوصیِ بررسی‌شده بگیرید و پیش از تغییر نصب موجود، [ارتقا و بازیابی](docs/UPDATES.md) را بخوانید.

فرمان زیر مخصوص **ارزیابی QA روی سرور تازه با assetهای تغییرناپذیر منتشرشده v1.0.56** است. نصب تازه را برای جایگزین کردن پنل موجود اجرا نکنید.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DashSaman/OV-PvNetwork/v1.0.56/install.sh)
```

Bootstrap نسخه و checksum آرشیو رسمی را کنترل می‌کند، ابزار و build را جدا آماده می‌کند و پیش از فعال‌سازی سلامت را می‌سنجد. Setup Mode پیش‌فرض فقط روی loopback است؛ [راهنمای نصب](docs/INSTALLATION.fa.md) دسترسی SSH و TLS عمومی را توضیح می‌دهد.

برای نصب موجود، از `sudo pvnetwork update v1.0.56 --dry-run --json` و [راهنمای ارتقا/rollback بررسی‌شده](docs/UPDATES.fa.md) شروع کنید. نسخه هدف فقط پس از تأیید asset رسمی و gateهای لازم قابل استفاده است؛ Fresh Install عملیات متفاوتی است.

## رفتارهای مهم حساب

- سهمیه ترافیک صفر یعنی پلن نامحدود با دوره پایه ۳۰روزه؛ محدودیت دستگاه و سیاست نود همچنان اعمال می‌شود.
- تمدید UUID، نام و تخصیص نود را نگه می‌دارد. حالت مصرف را آگاهانه انتخاب کنید.
- تغییر نام امن از v1.0.16، پروفایل قدیمی OpenVPN را فوراً بی‌اعتبار می‌کند. پس از موفقیت تغییر نام، پروفایل تازه را به کاربر بدهید.
- حضور، وضعیت نشست گزارش‌شده است؛ مجموع ترافیک از زمان بوت، سرعت فعلی اتصال نیست.
- تعمیر، همگام‌سازی، حذف و rollback نود دامنه و کنترل متفاوت دارند. پذیرفته شدن job به معنی پایان موفق آن نیست.

## بررسی عملیاتی

```bash
sudo pvnetwork status --json
sudo pvnetwork doctor --json
sudo pvnetwork database check --json
sudo pvnetwork backup --json
sudo pvnetwork jobs --json
```

برای نسخه دقیق v1.0.55، نصب تازه، تکرار نصب و bootstrap عمومی روی Ubuntu 22.04/24.04 و Debian 12 شواهد دارند. صدور واقعی ACME عمومی، ARM و VPS خالی مستقل در این مأموریت کامل آزموده نشده‌اند. CI، آرشیو/bootstrap عمومی و استقرار محدود مجاز نسخه دقیق v1.0.55 طبق گزارش تأیید شده‌اند؛ maintenance اندازه‌گیری‌شده پنل حدود ۴ دقیقه و ۲۸ ثانیه بود و هویت سرویس‌ها و VPNهای دیگر حفظ شد. workbench اولیه امنیت partial/unsealed است؛ پنج یافته تأییدشده در v1.0.46 و v1.0.50 اصلاح شده‌اند. این README گواهی تکمیل ممیزی مستقل امنیت نیست.
