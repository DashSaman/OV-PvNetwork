# نسخهٔ آزمایشی 1.0.42 — PVN-1026

بکاپ و بازیابی native و قابل بررسی، Update در staging، فعال‌سازی اتمی، توقف محدود نویسنده‌های پنل و recovery پایدار جایگزین تغییر مستقیم runtime شدند. کد قبلی، دادهٔ جاری و secrets حفظ می‌شوند. بازیابی واقعی PostgreSQL، داده‌های WAL در SQLite و کلیدهای رمزنگاری و اعتماد SSH بررسی می‌شوند. [محدوده، دستورها، شواهد و تست‌های باقی‌مانده](LIFECYCLE-CANDIDATE.fa.md). این نسخه هنوز نسخهٔ عمومی پایدار یا مستقر در Production نیست.

بررسی پورت canary اکنون TIME_WAIT سوکت سرور متوقف‌شده را هنگام retry فوری می‌پذیرد و listener فعال را همچنان رد می‌کند. دو تست واقعی سوکت Linux این رفتار بازیابی را پوشش می‌دهند؛ اشتراک listener یا تغییر فایروال اضافه نشده است.
