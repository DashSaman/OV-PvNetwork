# PVN-1033 — downloaded endpoint correctness

The real controller download handler prepends current remote/proto settings but
fails to remove old directives because its whitespace regexes are double-escaped.
The observed result has two remotes and two conflicting protocols.

1. Reproduce the handler output using real database node/user rows and a
   controlled profile response at the network boundary. Check valid and invalid
   cached profiles, leading whitespace and case variants, inline material and
   download privacy headers.
2. Correct only the two regex literals. Keep profile retry, identity and API
   authorization behavior unchanged; do not touch a VPN process or cached file.
3. Run focused and full Linux regression, update sequential metadata/bilingual
   notes, review the diff and require exact-head CI before the release gate.
