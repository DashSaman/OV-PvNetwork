# PVN-1034 — subscription QR data boundary

HTML escaping protects an attribute's markup, but the browser decodes it before
interpreting an inline JavaScript handler. Stored node names currently enter two
quoted JavaScript arguments in onclick/onkeydown. Node-write API tokens can set
names without receiving every panel API scope; online assigned-node rendering
and a user's QR activation are prerequisites for the stored browser path.

1. Retain a failing real Jinja/HTML-parser regression and controlled browser
   execution proof with a harmless synthetic marker, without live credentials.
2. Store the escaped URL and display name only in data attributes. Fixed event
   listeners read those strings and call the existing QR renderer. Keep keyboard
   activation and anchor navigation suppression.
3. Test real QR SVG generation with hostile strings at mobile/desktop sizes,
   EN/FA, dark/light and native Chromium zoom. Reject arbitrary script execution.
4. Run focused/full regression and frontend gates, update bilingual notes and
   sequential metadata, and obtain exact-head CI when GitHub becomes reachable.

The adjacent 13-language navigation matrix on v1.0.47 passed 6,318 views at nine
widths, three native zooms and two themes. This is layout/navigation evidence,
not linguistic certification of every translated phrase or an accessibility audit.
