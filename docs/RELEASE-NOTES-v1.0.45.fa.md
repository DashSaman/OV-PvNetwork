# نامزد v1.0.45 — PVN-1029

کنسول عملیاتی فارسی/انگلیسی، منوی ۲۵ گزینه‌ای، راهنمای اتوماسیون، محدودهٔ صریح تغییر، dry-run، تأیید و کد خروج ارائه می‌کند. بررسی‌های فقط‌خواندنی، لاگ محدود و پاک‌سازی‌شده و بستهٔ خصوصی پشتیبانی در کنار موتور بومی موجود بکاپ، update، restore، rollback و recover قرار دارند.

مدیریت نود از API مدیر اصلی و قواعد موجود اعتماد SSH استفاده می‌کند. همگام‌سازی انتخابی نود در worker، API و پنل وب، تخصیص کاربران و وضعیت drain را حفظ می‌کند. تمدید TLS فقط گواهی ACME پنل را انتخاب می‌کند و پس از بررسی Nginx، reload آرام انجام می‌دهد. تغییر پورت داخلی پنل، فرایند staging/canary موجود را با بازگشت دقیق env، build و پراکسی و بازیابی قطع ناگهانی تکمیل می‌کند.

۶۸۰ تست Linux با ۴ مورد PostgreSQL اجرا‌نشده، پیمایش واقعی ترمینال فارسی/انگلیسی و بررسی‌های مرورگر در ۹ عرض موفق بودند. نمونهٔ آزمایشگاهی دارای systemd به‌روزرسانی بومی را با حفظ جدول‌های داده و مهاجرت افزایشی مجاز گذراند. CLI نصب‌شده، حفظ env/دیتابیس/PID توسط Doctor، مجوز خصوصی پشتیبانی، ذخیرهٔ زبان و رفت‌وبرگشت واقعی پورت با رمز فعلی مدیر را تأیید کرد. worker تنظیمات در unit مستقل اجرا می‌شود و build از Node پین‌شدهٔ نصب‌شده استفاده می‌کند. CI سورس نهایی همچنان لازم است. این شواهد به‌معنای پایان مأموریت یا مجوز استقرار زنده نیستند.

این نسخه نامزد منتشرنشده است. artifact و CI نهایی، ترجمهٔ کامل، کنترل‌های کامل مأموریت، asset عمومی و استقرار مجاز Production باز هستند. نسخهٔ عمومی 1.0.37 و Production برابر 1.0.40 باقی است.
