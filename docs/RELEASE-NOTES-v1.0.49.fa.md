# نامزد v1.0.49 — PVN-1033

مسیر دانلود کنترلر، مقصد فعلی نود را به ابتدای فایل اضافه می‌کرد، ولی خط‌های
قدیمی `remote` و `proto` را به علت دو regex با escape اضافه حذف نمی‌کرد.
بنابراین پس از تغییر مقصد، فایل می‌توانست آدرس قدیمی یا تنظیم انتقال متناقض
داشته باشد. اصلاح همان دو عبارت، خط‌های قبلی را پیش از درج مقادیر فعلی حذف می‌کند.

آزمون، handler واقعی را با سطرهای واقعی SQLite و پاسخ کنترل‌شدهٔ پروفایل نود
اجرا می‌کند. روی کد قبلی شکست خورد و اکنون برای خط معمولی و گونه‌های دارای
فاصله/حروف متفاوت پاس می‌شود. محتوای CA، گواهی و کلید درون فایل، سایر دستورها،
سربرگ `no-store` و تلاش مجدد/رد پروفایل نامعتبر حفظ می‌شوند. دو آزمون هدفمند
پاس شدند. مجموعهٔ کامل Linux: ۷۱۱ آزمون، ۷۰۵ موفق و شش مورد مخصوص PostgreSQL
اجرانشده؛ کد PostgreSQL نسبت به نامزد ۱.۰.۴۸ با شش آزمون موفق تغییر نکرده است.

تغییر فقط بایت‌های خروجی دانلود را اصلاح می‌کند؛ فایل cache، هویت و فرایند
نود یا VPN تغییر نمی‌کنند. migration لازم نیست. rollback کد، رفتار قبلی دانلود
را با حفظ داده‌ها برمی‌گرداند. CI نهایی همان commit، اعتبارسنجی باقی مأموریت،
انتشار و مجوز محدود Production هنوز gateهای باز هستند.
