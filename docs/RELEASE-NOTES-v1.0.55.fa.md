# نامزد v1.0.55 — PVN-1039

استقرار مجاز v1.0.54 پیش از فعال‌سازی متوقف شد؛ چون فایل تشخیصی `data/app.log` هنگام بکاپ دیتابیس تغییر می‌کرد. این اصلاح فقط همین فایل را از آرشیو وضعیت قابل‌بازیابی و سورس کنار می‌گذارد. لاگ زنده حذف یا خالی نمی‌شود. ثبات و checksum فایل‌های دیگر، لاگ‌های ناشناخته، اعتماد SSH و کلیدهای رمزگذاری و Push همچنان کنترل می‌شود.

آزمون واقعی Linux ابتدا همان خطا را بازتولید کرد و پس از اصلاح، هر سه حالت پاس شدند: بکاپ با نوشتن هم‌زمان لاگ و بازیابی واقعی SQLite، رد تغییر کلید و رد تغییر فایل ناشناخته. رابط کاربری، schema، VPN، نود، مسیر و فایروال در این patch تغییر نکرده‌اند؛ تصاویر Demo نسخه 1.0.54 همین رابط را نمایش می‌دهند.

CI دقیق commit، آرشیو تغییرناپذیر و نصب عمومی، بکاپ و canary تازه و استقرار محدود مجاز هنوز gate هستند. این نسخه QA است و پایان انتشار پایدار اعلام نشده است. [شواهد و محدودیت‌ها](VALIDATION-v1.0.54.md).
