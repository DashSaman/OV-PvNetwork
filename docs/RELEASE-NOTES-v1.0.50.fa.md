# نامزد v1.0.50 — PVN-1034

نام نود پس از decode شدن entityهای HTML می‌توانست وارد رویداد JavaScript داخل صفحه شود. دارندهٔ مجوز نوشتن نود و یک نود قابل دسترس می‌توانست نامی ذخیره کند که هنگام فعال‌کردن QR آن نود در صفحهٔ اشتراک، اسکریپت اجرا کند. آزمون فقط نشانگر بی‌خطر و دادهٔ ساختگی داشت؛ بهره‌برداری زنده یا دسترسی به اعتبارنامه انجام نشد.

اکنون نام و URL با autoescape در data attribute ذخیره می‌شوند و رویدادهای ثابت، همان رشته‌ها را به QR موجود می‌دهند. عنوان و توضیح همچنان textContent هستند. هویت نود، کانفیگ، سهمیه و ساختار دیتابیس تغییر نمی‌کنند.

اشکال روی کد قبلی با parser و مرورگر بازتولید شد. هشت آزمون هدفمند QR پاس شد. آزمون واقعی Jinja و مرورگر در ۲۴ حالت فارسی/انگلیسی، روشن/تاریک، موبایل/دسکتاپ و زوم بومی ۱۰۰/۱۲۵/۱۵۰ درصد پاس شد؛ هر حالت ماوس، Enter، Space، محتوای دقیق QR، SVG واقعی و Escape را بررسی می‌کند. ماتریس ۱۰۸ حالتی ویرایش سریع روی این build پاس شد. مجموعهٔ Linux: ۷۱۲ آزمون، ۷۰۶ موفق و شش مورد مخصوص PostgreSQL اجرا نشده؛ lint و build فرانت‌اند موفق بودند. رفتار PostgreSQL نسبت به شش آزمون واقعی موفق نامزد ۱.۰.۴۸ تغییر نکرده است.

هر ۱۳ زبان موجود حفظ شده‌اند. بررسی مستقل ۶۳۱۸ نمای ناوبری/چیدمان روی نسخهٔ ۱.۰.۴۷، همهٔ زبان‌ها، پوسته‌ها، نه عرض و زوم بومی را پاس کرده و ابزار بازتولید دستی اضافه شده است؛ این نتیجه تأیید کامل ترجمه یا همهٔ فناوری‌های کمکی نیست.

[تصاویر Demo فعلی](CURRENT-DEMO.fa.md) فقط دادهٔ ساختگی دارند. CI همان commit، بستهٔ تغییرناپذیر نهایی، باقی مأموریت، انتشار و مجوز محدود Production هنوز gate هستند. rollback کد، رفتار آسیب‌پذیر قبلی را بازمی‌گرداند و وضعیت امن بلندمدت محسوب نمی‌شود.
