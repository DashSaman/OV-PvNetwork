# v1.0.61، کد دقیق تأییدشده — PVN-1045

تغییر نسبت به QA60: درخواست واقعی صفحهٔ اشتراک با API قفل‌شدهٔ Starlette سازگار می‌شود؛ request/name/context صریح ارسال می‌شوند. escape محتوا، دسترسی نود، وضعیت آفلاین، خطاهای404 و اصلاح وابستگی60 حفظ می‌شوند. [تست واقعی route و gateها](VALIDATION-v1.0.61.md).

هر هشت بررسی CI کد دقیق، شامل شش تست واقعی مسیر اشتراک، ممیزی وابستگی و مرورگر/build پاس شدند؛ دانلود کامل ناشناس و هر شش نصب عمومی هم پاس شدند؛ بررسی تکمیلی tag هنوز در جریان است. شمارهٔ اجراها و شرط‌های باقی‌مانده در شواهد ثبت‌اند. پنل هنوز59 است و مالک ادامهٔ کار هم‌زمان را تأیید کرده؛ سپس ابتدا60 و بعد61 با بکاپ تازه، بازیابی واقعی، canary و rollback آماده مستقر می‌شوند. ساختار داده و تنظیمات نود/VPN تغییر نمی‌کنند و این نسخه هنوز Stable اعلام نشده است.
