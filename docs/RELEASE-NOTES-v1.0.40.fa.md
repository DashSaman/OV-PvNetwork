# v1.0.40 — PVN-1024: محدودسازی و تشخیص صحیح ترمیم خودکار

وضعیت: نامزد انتشار؛ انتشار عمومی انجام نشده است.

این patch پس از v1.0.39 قرار دارد و محدوده تغییر آن در دفتر taskهای `AGENTS.md` ثبت شده است. Migration دیتابیس یا تغییر تنظیمات VPN لازم نیست.

تست اختصاصی، gateهای موجود CI لینوکسی و تست‌های مرتبط مرورگر مبنای اعتبارسنجی‌اند. نتیجه commit نهایی و شواهد استقرار در دفتر task و گزارش خصوصی ثبت می‌شوند؛ وضعیت نامزد به معنی تکمیل نهایی نیست.

در ارتقا باید تنظیمات، دیتابیس، Certificateها، Subscriptionها و اتصال‌های موجود حفظ شوند. بکاپ native دیتابیس و artifact دارای checksum لازم است. برای این استقرار از updater قدیمی CLI استفاده نمی‌شود. Rollback فایل‌های برنامه، helper یا index را از بکاپ مشخص برمی‌گرداند؛ فایل‌های قدیمی فرانت‌اند تا پایان اعتبارسنجی باقی می‌مانند.

موارد بازِ سخت‌سازی کل پروژه: دسترسی عمومی و TLS نصب تازه، کنترل یکپارچگی Installer/Update، بکاپ و rollback دیتابیس در CLI و E2E واقعی نصب نود/ترافیک VPN. این نامزدها به معنی FINAL یا RELEASE-READY بودن کل پروژه نیستند.
