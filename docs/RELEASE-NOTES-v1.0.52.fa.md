# نامزد v1.0.52 — PVN-1036

آرشیو خصوصی دقیقِ نامزد ۱.۰.۵۱ در نصب تازهٔ واقعی Ubuntu 24.04 روی دستور Bash متوقف شد. blobهای Git دارای LF بودند، ولی git archive با core.autocrlf=true این میزبان ویندوزی هر نه فایل shell را CRLF صادر کرده بود. این شکست ساخت بسته است و نشان نمی‌دهد بسته‌های عمومی قبلی که روی Linux ساخته شده‌اند همان بایت‌ها را داشته‌اند.

ویژگی‌های مخزن اکنون LF را برای متن تشخیص‌داده‌شده الزام می‌کنند و تصویر، فونت و آرشیو باینری صریحاً بدون تبدیل باقی می‌مانند. منطق نصب، وابستگی، runtime و رابط تغییر نکرده‌اند؛ تصاویر نسخه‌دار ۱.۰.۵۱ همچنان وضعیت فعلی را نشان می‌دهند.

چهار آزمون با مخزن Git موقت واقعی و ویژگی‌های همین پروژه اجرا می‌شوند: بایت دقیق shell و بیت اجرا، hash باینری و برابری آرشیو میان دو تنظیم autocrlf بررسی می‌شوند؛ فایل صادرشده واقعاً در Bash لینوکس اجرا می‌شود. سیاست قبلی پیش از اصلاح شکست خورد. چهار آزمون و دوازده قرارداد مرتبط Linux پاس شدند؛ روی Windows سه مورد مرتبط موفق و اجرای Bash صریحاً اجرا نشده است.

بستهٔ جدید از commit تمیز باید نصب تازه، تکرار نصب و چرخهٔ بومی را پیش از انتشار پاس کند. بستهٔ خصوصی ناموفق فقط شاهد آزمون است و منتشر نمی‌شود. tag و فایل منتشرشدهٔ تاریخی بازنویسی نمی‌شود. migration و تغییر Production در این کار نیست؛ CI و بستهٔ نهایی و مجوز مشخص Production هنوز gate هستند.

نخستین آرشیو اصلاح‌شده از commit `91fa091e96d22b3f8ae6d6936579535ccc7935f0` با SHA256 `2a06712ac1ea1ccefba1f1ce7fc6375f3428bf1151f9ff23b312c033a2b1cd9f`، ارتقا و rollback واقعی ایزولهٔ ۱.۰.۴۵ به ۱.۰.۵۲ و برگشت را با حفظ سطرها، تنظیمات و Health پاس کرد. نصب تازهٔ Ubuntu از Bash عبور کرد، ولی فضای میزبان محلی تمام و فایل‌سیستم مهمان read-only شد؛ این نتیجه PASS نصب تازه نیست. تعمیر یا restart عمومی میزبان انجام نشد.

ماتریس مستقل CI مهمان‌های systemd موقت Ubuntu 22.04/24.04 و Debian 12 را از تصویر ثابت می‌سازد. هرکدام آرشیو همان commit با تنظیم صادرات ویندوزی را می‌گیرد و نصب تازه/تکرار، سرویس واقعی، پراکسی، فایل‌های UI، سلامت و revision SQLite، مجوز فایل محرمانه و CLI نصب‌شده را بررسی می‌کند. پورت میزبان یا لاگ خام اعتبارنامه منتشر نمی‌شود و فقط مهمان و تصویر متعلق به همان آزمون پاک می‌شود. تا موفقیت job دقیق، این موارد pending هستند؛ ACME عمومی و VPS خارجی همچنان مشروط‌اند.
