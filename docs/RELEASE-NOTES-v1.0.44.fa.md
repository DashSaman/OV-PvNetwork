# نامزد v1.0.44 — PVN-1028

مدیر اصلی می‌تواند از مدیریت وب بکاپ تأییدشدهٔ نود بسازد و دانلود کند، بکاپ آپلود کند و روی همان نود بازیابی کند. ورود SSH با رمز/کلید و اثر انگشت تأییدشده، منبع بررسی‌شده و انتقال خصوصی محدود استفاده می‌شود. اتصال فایل به هویت نود، انقضای یک‌ساعته، SHA256، مجوز خصوصی، پاک‌سازی محافظت‌شده، job بدون اسرار و تأیید صریح حالت آفلاین/توقف/شروع سرویس، قواعد ایمنی بومی را حفظ می‌کنند.

اعتبارسنجی محلی: ۶۲۸ تست، ۶۲۴ موفق و چهار مورد وابسته به PostgreSQL کنار گذاشته شد؛ کنترل‌های فارسی/انگلیسی در ۹ عرض؛ build/lint، lockfile، audit وابستگی اجرا و بررسی امنیتی هدفمند. در نود TCP آزمایشگاهی، بکاپ/دانلود/آپلود/بازیابی واقعی SSH، PID سرویس VPN، تنظیمات، اسرار و مصرف بدون کاهش را حفظ کرد. کلاینت موجود با همان PID پس از بازیابی ۴٬۳۲۰٬۰۰۰ بایت دانلود و ۲٬۸۶۰٬۰۰۰ بایت آپلود از تونل عبور داد.

این نامزد به‌صورت PR زنجیره‌ای draft ارائه می‌شود. CI دقیق commit، باقی مأموریت، ترجمهٔ رشته‌های تازه در زبان‌های دیگر، artifact نهایی سیستم‌عامل‌ها، انتشار عمومی تغییرناپذیر و استقرار مجاز Production باز هستند. نسخهٔ عمومی پایدار 1.0.37 و Production برابر 1.0.40 باقی است. برای این نامزد زیرساخت زنده تغییر نکرد.
