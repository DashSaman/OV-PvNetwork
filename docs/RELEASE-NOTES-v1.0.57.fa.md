# نسخهٔ کاندید 1.0.57 — PVN-1041

تغییر نسبت به 1.0.56: پنجره‌ها فوکوس کیبورد را داخل خود نگه می‌دارند و پس از بسته‌شدن برمی‌گردانند؛ منوی عملیات و «بیشتر» موبایل با کیبورد کار می‌کنند. برچسب فیلدها، بخش‌های اسکرول‌شونده، خطای ورود و تیترها اصلاح شده‌اند. لینک عبور به محتوا، حلقهٔ فوکوس، کاهش حرکت و کنتراست تم روشن بهتر شده است. QR اشتراک با پنجرهٔ native باز می‌شود و escaping و رفتار دانلود قبلی حفظ شده‌اند.

[راهنمای تصویری](ACCESSIBILITY.fa.md) و [محدودهٔ واقعی تست‌ها](VALIDATION-v1.0.57.md) را بخوانید. این نسخه کاندید QA است؛ اعلام Stable نیست. CI دقیق، انتشار ثابت، bootstrap عمومی و استقرار Production gateهای جدا هستند. این مرحله سرویس زنده، VPN، دیتابیس، نود، فایروال یا گواهی را تغییر نمی‌دهد. برای پنل موجود از مسیر امن بکاپ و ارتقا استفاده کنید؛ نصب تازه را روی آن اجرا نکنید.
