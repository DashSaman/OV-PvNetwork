# نسخهٔ QA بررسی‌شده 1.0.57 — PVN-1041

تغییر نسبت به v1.0.56: فوکوس پنجره‌های پنل و QR اشتراک داخل آن‌ها می‌ماند، Escape آن‌ها را می‌بندد و فوکوس دقیقاً به دکمهٔ آغازکننده برمی‌گردد. منوها با کیبورد کار می‌کنند؛ برچسب‌ها، ناحیه‌های اسکرول، خطای ورود و تیترها اصلاح شدند. لینک عبور به محتوا، حلقهٔ فوکوس، کاهش حرکت و کنتراست متن/منوی روشن بهتر شده‌اند. رفتار مجوز API و عملیات VPN/نود حفظ شده است.

CI دقیق، 228 اسکن axe، 136 بار بازشدن پنجره و144 اندازه‌گیری فوکوس و نصب عمومی شش مهمان x86/ARM پاس شدند. آرشیو ثابت با دانلود ناشناس تطبیق داده شد. موارد incomplete/دستی حفظ شده‌اند؛ این نتیجه گواهی جامع WCAG نیست. ACME عمومی، چرخهٔ VPS/کلاینت مستقل و استقرار مجاز Production gateهای جدا هستند. Stable همچنان v1.0.37 و نسخهٔ زنده v1.0.55 است.
