# PVNetwork Panel v1.0.22 — نصب خودکار قابل‌اتکای نود

`PVN-1008` مخرب‌ترین حالت‌های خرابی نصب‌کننده خودکار «افزودن نود» را تعمیر می‌کند.

## مشکل ۱ — «IP پنل»
فرم افزودن نود فیلد «IP عمومی پنل» را با `window.location.hostname` پیش‌پر می‌کرد. وقتی پنل از طریق دامنه (پشت Cloudflare/nginx) استفاده می‌شود، این مقدار hostname است نه IP:

- اعتبارسنجی سخت‌گیرانه `ip_address()` در بک‌اند بلافاصله آن را با خطای خام و نامفهوم رد می‌کرد (`X does not appear to be an IPv4 or IPv6 address`) — دیپلوی اصلاً شروع نمی‌شد.
- پر کردن دستی IP هم خطاپذیر بود: هر اشتباهی (NAT، پراکسی، آدرس قدیمی) باعث می‌شد نود کامل نصب شود، سپس فایروال نود منبع اشتباه را allowlist کند و وریفای پنل در پایانِ بیش از ده دقیقه کار fail شود.

## راه‌حل — تشخیص خودکار منبع پنل
- `panel_ip` اکنون در کل مسیر اختیاری است (اسکیما، API و رابط کاربری).
- وقتی خالی باشد یا IP literal نباشد، اسکریپت نصب منبع allowlist را **روی خود نود از نشست SSH** می‌سازد (`$SSH_CLIENT`/`$SSH_CONNECTION`): پنل برای نصب از طریق SSH به نود وصل می‌شود، پس این تضمین‌شده همان آدرسی است که فراخوانی‌های API او از آن می‌آیند.
- تصمیم (صریح یا خودکار) در ترمینال دیپلوی لاگ می‌شود؛ منبع غیرقابل‌تشخیص با نشانگر روشن `PANEL_SOURCE_IP_UNRESOLVED` قطع می‌شود به‌جای نوشتن فایروال خراب.
- فیلد اختیاری برای حالت نادری که ترافیک API پنل واقعاً از آدرسی غیر از SSH خارج می‌شود باقی مانده است.

## مشکل ۲ — درج قواعد فایروال
قواعد allow در جایگاه ۲ از INPUT درج می‌شدند؛ روی سرورهایی که زنجیره INPUT آنها صفر یا یک قاعده دارد این کار خطا می‌دهد و نصبِ در غیر این صورت موفق را رول‌بک می‌کند.

## راه‌حل — شکل مقاوم قواعد
- درج گاردشده در جایگاه ۱ و الحاق DROP در انتها (ترتیب allow-قبل-from-drop حفظ می‌شود).
- منابع IPv6 شاخه allow متناظر `ip6tables` می‌گیرند؛ DROP عمومی قبلی IPv6 (که می‌توانست پنل‌های IPv6-reachable را قفل کند) حذف شد.

## موارد دیگر
- خطاهای وریفای پس از نصب اکنون «پنل به API نود دسترسی نداشت» با بررسی‌های مشخص گزارش می‌کنند، نه رشته timeout خالی.
- برچسب‌های فیلد SSH فرم افزودن نود در هر ۱۳ زبان ترجمه شدند.
- تست‌های قرارداد متمرکز، دسته‌بند تشخیص خودکار، تحمل hostname، literal جاسازی‌شده، شکل قواعد، شاخه IPv6، اسکیمای اختیاری و سیم‌کشی مودال را پوشش می‌دهند.

## دامنه و ایمنی
فقط مسیر نصب خودکار افزودن نود تغییر می‌کند. ثبت دستی نود، نودهای موجود، OpenVPN، Listenerهای سازگاری Router، پروفایل‌ها و سشن‌ها دست‌نخورده‌اند. تنها ریاستارت دیپلوی، `pvnetwork-panel.service` است.

## گیت ریلیز
CI روی هد دقیق، تعویض اتمیک فرانت‌اند به‌همراه دلتای بک‌اند، بررسی سلامت محلی/عمومی، آرتیفکت بهینه‌شده با انتشار SHA256 و وریفای دانلود مجدد عمومی.
