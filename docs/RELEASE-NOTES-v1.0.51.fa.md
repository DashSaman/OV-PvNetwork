# نامزد v1.0.51 — PVN-1035

پوستهٔ روشن متن تیره داشت، ولی پوستهٔ ظاهریِ بعدی پس‌زمینهٔ ورودی را تیره می‌کرد. در مرورگر واقعی، کنتراست ورودی قبلی حتی با دو حد نهایی پس‌زمینه فقط ۱٫۱۳ تا ۲٫۱۶ بود؛ مقدار فرم کاربر، نود و امنیت کم‌خوانا می‌شد.

ورودی، انتخاب‌گر و کادر متن اکنون پس‌زمینه و متن را از همان پوستهٔ موجود می‌گیرند؛ حالت فوکوس و گزینه‌ها نیز هماهنگ‌اند. placeholder رنگ صریح و opacity کامل دارد. ابعاد، رفتار API، داده و ترجمه تغییر نمی‌کنند.

آزمون رندر، مقدار، placeholder و حالت فوکوس را در کاربران، نود و پنجرهٔ ساخت آن، امنیت، مانیتورینگ و پهنای باند بررسی می‌کند. build قبلی شکست خورد؛ build اصلاح‌شده در ۱۰۸ ترکیب دو زبان، دو پوسته، نه عرض و زوم بومی ۱۰۰/۱۲۵/۱۵۰ درصد، با ۷۱۲۸ مشاهدهٔ کنترل و حداقل کنتراست ۴٫۵ پاس شد. کنترل کاملاً شفاف سربرگ خارج از این آزمون مقدار فرم است؛ این نتیجه تأیید WCAG کل صفحه نیست. بیست آزمون مرتبط Linux و lint/build پاس شدند. نتیجهٔ تعامل مجاور و CI و بستهٔ نهایی جداگانه ثبت می‌شود.

[Demo فعلی](CURRENT-DEMO.fa.md) دادهٔ ساختگی دارد. این تغییر CSS به migration یا restart نیاز ندارد. rollback رنگ‌های کم‌خوانای قبلی را برمی‌گرداند. انتشار و مجوز مشخص Production هنوز gate هستند.

آزمون تعامل مجاور ویرایش سریع: هر ۱۰۸ حالت زبان، پوسته، عرض و زوم بومی پاس شد.

در همان بررسی Demo، عنوان تیرهٔ پوستهٔ روشن روی گرادیان تیره نیز کنتراست ۱٫۰۱ تا ۲٫۷۰ داشت. رنگ عنوان مشترک در هر دو پوسته روشن شد؛ آزمون جداگانهٔ چهارحالتی زبان و پوسته، دو سر گرادیان با پس‌زمینه‌های حدی را با حداقل ۳ برای متن بزرگ و ضخیم بررسی می‌کند. ماتریس ۱۰۸ حالتی مقدار فرم فقط پیش از این افزودن رنگ عنوان اجرا شده است.
