# v1.0.44 candidate — PVN-1028

Main administrators can create and download a verified native node backup, upload a backup and restore it on the same node from Web management. Pinned SSH password/key authentication carries checked source and bounded private archive streams. Node-bound one-hour controller copies, SHA256 checks, private permissions, guarded cleanup, sanitized jobs and explicit offline/downtime/start confirmation preserve the existing native safety rules.

Local validation: 628 tests (624 passed, four PostgreSQL-dependent skips); English/Persian controls at nine viewport widths; build/lint, lock checks, runtime dependency audit and focused static security checks. An owned native TCP node preserved VPN PID/configuration/secrets and monotonic accounting during actual SSH backup/download/upload/restore. Its existing client retained its PID and transferred 4320000 download / 2860000 upload bytes through TUN after restore.

This is a stacked draft candidate. Exact-commit CI, remaining full-mission checks, complete new-string translations beyond EN/FA, final OS artifacts, immutable public publication and owner-authorized Production remain open. Public stable is still 1.0.37 and Production is still 1.0.40. No live infrastructure was changed for this candidate.
