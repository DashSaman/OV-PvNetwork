# نامزد v1.0.47 — PVN-1031

ویرایش سریع اکنون یک فرم ثابت بیرون از محدودهٔ اسکرول افقی جدول دارد. فرم با
عرض محتوای موجود تطبیق پیدا می‌کند، هنگام بازشدن فوکوس را به اولین ورودی قابل
ویرایش می‌برد و با عبور از اندازهٔ موبایل/دسکتاپ پیش‌نویس را از دست نمی‌دهد.
عملیات کاربر و قواعد دسترسی حفظ شده‌اند.

در عرض کم، نام و لوگو و کنترل‌های بالای صفحه در دو ردیف قرار می‌گیرند. اندازهٔ
لمس کنترل‌ها حداقل ۴۴ پیکسل است، خروج نام قابل خواندن برای screen reader دارد
و فضای سربرگ ثابت در محتوا رعایت می‌شود. لوگوی ورود و پنل در build قرار می‌گیرد
و به مسیر جداگانهٔ بیرون از پنل وابسته نیست.

آزمون مرورگر از زوم واقعی Chromium استفاده و مقدار زوم و عرض CSS را بررسی
می‌کند: هر ۱۰۸ حالت فارسی/انگلیسی، دو تم روشن/تاریک، ۹ عرض و زوم ۱۰۰، ۱۲۵ و
۱۵۰ درصد پاس شدند. ۴۰ آزمون هدفمند و lint/build نیز محلی پاس شدند. بررسی‌ها شامل محدودهٔ
فرم و سربرگ، اندازهٔ لمس، فوکوس و ذخیره با صفحه‌کلید/ماوس، حفظ پیش‌نویس هنگام
تغییر اندازه، بارگذاری لوگو، خطاهای اجرای صفحه و ترتیب درخواست‌های تغییر است.
افزونهٔ موقت آزمون فقط در پروفایل جداگانهٔ مرورگر اجرا می‌شود و جزو محصول نیست.
